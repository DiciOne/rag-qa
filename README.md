# 📚 个人知识库问答系统（RAG）

基于 **RAG（检索增强生成）** 的个人知识库问答系统：把本地笔记/文档导入向量数据库，用自然语言提问，系统从知识库中检索相关内容并生成回答，**可追溯信息来源**。

## ✨ 功能特点

- **本地私有化部署**：模型全部跑在本机（Ollama），数据不出本地，无需 API 费用
- **语义检索**：使用向量检索（Chroma + bge-m3），能理解"意思相近但字面不同"的表达
- **防幻觉回答**：提示词约束 + 仅基于检索材料回答，对知识库外问题返回"未找到"，不编造
- **来源追溯**：每条回答标注信息来源文档

## 🛠 技术栈

| 组件 | 用途 |
|---|---|
| Python | 主程序语言 |
| Chroma | 向量数据库（持久化存储） |
| Ollama | 本地模型运行环境 |
| bge-m3 | 嵌入模型（中文语义检索） |
| qwen2.5:3b | 问答生成模型 |

## 📦 环境要求

- Windows / Linux / macOS
- Python 3.10+
- [Ollama](https://ollama.com) 已安装并运行

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install chromadb requests
```

### 2. 拉取模型

```bash
ollama pull bge-m3      # 嵌入模型（中文检索效果好）
ollama pull qwen2.5:3b  # 问答模型
```

### 3. 放入你的知识文档

把 `.txt` / `.md` 文档放入 `knowledge/` 文件夹（示例：Python 笔记、大模型笔记）。

### 4. 运行

```bash
python rag.py
```

首次运行会自动建库（读取文档 → 切块 → 向量化 → 存入 Chroma），之后直接问答：

```
问题: 列表推导式怎么写？
回答: [x*x for x in range(5)] 生成平方列表
来源: python笔记.txt
```

输入 `exit` 退出。

## 🧠 工作原理

```
┌─────────┐  切块  ┌──────┐  向量化  ┌────────┐
│ 知识文档 │ ────→ │ 文档块 │ ──────→ │ Chroma │
└─────────┘        └──────┘          └────────┘
                                        ↑ 检索
用户问题 ──→ 向量化 ──→ 找到相关块 ──→ 拼成材料
                                        ↓
                                    qwen2.5:3b 生成回答
```

三步核心：**文档切块 → 向量检索 → 基于材料生成**。

## 💡 关键技术说明

- **为什么选 bge-m3 而不是 nomic-embed-text**：实测对比中，nomic-embed-text 对中文的语义区分度不足（检索结果混淆），bge-m3 在中文场景命中率显著提升
- **metadata 的作用**：每个文档块记录来源文件名，回答时追溯"这段知识来自哪个文档"
- **防幻觉设计**：提示词明确要求"只基于材料回答，材料中没有就说没有"
