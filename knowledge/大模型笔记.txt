# 大模型学习笔记

## 什么是提示词工程
- 提示词是给大模型的指令，质量直接影响输出质量
- 五要素：角色、任务、输入、格式、约束
- 少样本示例（few-shot）比单纯指令更稳定
- 思维链（chain-of-thought）让模型分步思考，提高推理准确率

## 什么是 RAG
- RAG = 检索增强生成（Retrieval-Augmented Generation）
- 解决大模型不知道私有知识的问题
- 三步：文档切块 → 向量检索 → 基于材料生成回答
- 向量检索比关键词检索强在"语义理解"

## 大模型 API 调用要点
- messages 是复数（对话历史），返回的 message 是单数
- temperature 控制随机性：0 稳定，1 放飞
- stream=True 开启流式输出（打字机效果）
- 模型只输出文本，JSON 需要用 json.loads 解析

## Chroma 向量数据库
- 用来存文档向量，支持语义检索
- 中文内容建议用 bge-m3 嵌入模型
- collection.query() 做检索，n_results 控制返回数量
